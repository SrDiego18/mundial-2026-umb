# Revisión de la rúbrica

## 1. Integración semántica

- Un solo `main`.
- `header`, `nav`, `section`, `article`, `aside`, `figure`, `form`, `footer`.
- Navegación por anclas internas.
- Pestañas accesibles con `role="tab"` y `role="tabpanel"`.

## 2. Responsive

Breakpoints principales:

- 1100 px
- 820 px
- 600 px
- 390 px

Incluye adaptación específica para iPad/tablet y celular.

## 3. Accesibilidad

- `label` asociado a todos los campos.
- `aria-selected` en pestañas.
- navegación por teclado en pestañas.
- enlace “Saltar al contenido”.
- textos alternativos.
- foco visible.
- `role="status"`.

## 4. Organización

- HTML, CSS y JS separados.
- comentarios.
- clases.
- herencia.
- polimorfismo.
- datos separados de la lógica.
- documentación y fuentes.
